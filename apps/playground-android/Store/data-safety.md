# Google Play data safety declaration

The Android playground does not collect or share user data. It does not include advertising,
analytics, tracking, account, or remote-content SDKs and requests no sensitive Android permissions.
Interactive component values remain in process memory for the current app session.

Before each submission, verify the merged release manifest and dependency graph still support this
declaration. Google Play requires the Data safety form and privacy-policy URL even when an app does
not collect data.
