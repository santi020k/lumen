# Lumen HarmonyOS Playground (preview)

<!-- cspell:words rport -->

A HarmonyOS NEXT host for the [React Native playground](../playground-react-native/README.md), built
with React Native for OpenHarmony (RNOH) 0.86. It renders the same screens from
`apps/playground-react-native/src`. Read [HarmonyOS NEXT (preview)](../../docs/harmonyos.md) for
versions, verification status and known gaps.

## Layout

- `index.ts` registers the shared playground as `LumenPlayground`, the `appKey` used by
  `harmony/entry/src/main/ets/pages/Index.ets`.
- `metro.config.js` adds RNOH's resolver, watches the workspace, and maps `expo-status-bar` to
  `src/expo-status-bar.tsx`.
- `harmony/` is the DevEco Studio project generated by `react-native init-harmony`. During the
  hvigor build, autolinking writes `RNOHPackagesFactory`, `autolinking.cmake` and other native
  glue, which Git ignores.

## Check the JavaScript bundle

No HarmonyOS tooling is needed:

```bash
pnpm install --frozen-lockfile
pnpm --filter @santi020k/lumen-react-native... run build
pnpm run check:harmony-bundle
```

The bundle is written to `apps/playground-harmony/.harmony-check/`.

The workspace overrides Harmony CLI 0.86.1's archive dependency to patched `tar` 7.5.23 and its
older codemod runner to `micromatch` 4.0.8. A pnpm patch replaces the CLI's default `tar` import
with a namespace import for the newer CommonJS exports. `pnpm run check:security` verifies archive
extraction and codemod ignore patterns alongside the dependency audit. Keep these overrides and
the patch until the upstream CLI adopts patched dependencies and compatible imports.

## Run on an emulator or device

Prerequisites: DevEco Studio with the HarmonyOS SDK, a Huawei developer account, and a HarmonyOS
NEXT emulator or device with developer mode enabled.

1. Copy `harmony/build-profile.template.json5` to `harmony/build-profile.json5`. The copy holds your
   signing configuration and stays out of Git.
2. Build the release bundle with `pnpm run playground:harmony:bundle`, or start Metro with
   `pnpm run playground:harmony` for a debug build. Debug builds load from Metro, so forward the port
   with `hdc rport tcp:8081 tcp:8081`.
3. Open `apps/playground-harmony/harmony` in DevEco Studio and wait for the hvigor sync and `ohpm`
   install to finish.
4. Sign in, then open **File > Project Structure > Signing Configs** and select
   **Automatically generate signature**.
5. Select the `entry` run configuration and press **Run**.
