# Figma Community artwork

These 1920 × 1080 PNGs are the covers and carousel images prepared for the three
Lumen Community listings on November 6, 2026. Each row lists the four screenshots in
publication order. The [Figma guide](../../../../../docs/figma.md) links to the editable files.

three covers so readers can recognize the corresponding resources on Figma Community.
