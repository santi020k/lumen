# Archived documents

These files record past release plans, audits, and consumer findings. They are kept as evidence
and are not current guidance. Statements about APIs, versions, or open work describe the state of
the project when each file was written.

Open work lives in the [open backlog](../feature-roadmap.md#open-backlog). Current guides stay at
the top level of [`docs/`](..). When a plan or audit is finished, move it here and update its
links rather than leaving it next to the guides.
