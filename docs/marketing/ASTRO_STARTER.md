**Status: held until the public demo and source pass verification.** See the

## Distribution order

1. Verify the [starter page](https://lumen.santi020k.com/starters/astro) and
   [GitHub source](https://github.com/santi020k/lumen/tree/main/examples/astro-starter) after
   deployment. Follow the production page’s setup command from an empty directory, run a
   production build, and open all four examples. Check that theme controls, mobile navigation,
   and every download or source link work. Browser editor launches are not supported by the
   starter's pinned pnpm toolchain; do not advertise an editable browser runtime.
2. Submit one free starter through the [Astro Developer Portal](https://portal.astro.build).
   Sign in with the maintainer’s GitHub account. Record the submission separately from the
   eventual listing URL. Use the title, description, source, demo, and images below.
3. When the next npm release includes `astro-component`, verify the published package keywords
   and check the [Astro Integrations directory](https://astro.build/integrations/) after its next
   weekly refresh. Astro indexes packages with the documented keyword automatically. If the
   listing is still missing after the refresh, follow [Astro’s submission
   guidance](https://docs.astro.build/en/guides/integrations/) before opening a support issue.
4. Share the walkthrough on Santiago’s personal LinkedIn profile and in an Astro community that
   allows maintainer posts. Disclose who built it. Direct readers to the starter page. Record
   publication URLs and dates in the [publishing queue](PUBLISHING_QUEUE.md), then use the
   [28-day measurement plan](MEASUREMENT.md#astro-starter-campaign-baseline).

**Short description**

A free Astro starter with four editable layouts built with Lumen UI. Explore a landing page,
storefront, dashboard, and portfolio, then start your project with the layout and theme you like.

**Full description**

Start an Astro project with a working layout and a set of UI components you can reuse as it
grows. The starter includes landing, storefront, dashboard, and portfolio examples. Each uses the
same Lumen components and theme tokens. Switch themes in the demo, then use the setup
instructions to run the MIT-licensed source locally and replace the example content.
The storefront and dashboard use sample data for their interfaces.

Use four production captures, one per layout. Lead with the landing page. Capture each at the
same desktop viewport with its default theme, then take one additional capture of a contrasting
theme if the listing supports it. Write alt text describing what each image actually shows.
